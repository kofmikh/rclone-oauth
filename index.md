# Personal rclone Google Drive connection

This is a personal OAuth application used by the GitHub user
kofmikh to connect rclone to their own Google Drive.

The application lets rclone list, read, upload, modify and delete
files in the owner's Google Drive, according to the permissions
granted during Google sign-in.

This application is for personal use and is not offered as a
public service.
